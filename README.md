# Pong Survival

## Project Overview
Pong Survival is a complete Unreal Engine 5 project inspired by the classic Pong game. This project was a valuable learning experience, and I am proud of the progress I made throughout its development.

## What I Learned
- Gained hands-on experience with Unreal Engine 5 project structure and workflow
- Improved my understanding of game logic, especially for ball movement and collision
- Practiced organizing code and Blueprints for better maintainability

## Reflections
While I am happy with the current state of the project, I recognize there are areas for improvement:
- Some parts of the code could be cleaner and more efficient
- The ball logic, in particular, could be further refined for better gameplay

## Feedback
If you have any suggestions or feedback, I would greatly appreciate it! Constructive criticism is welcome as I continue to learn and grow as a developer.

## Getting Started
To run the project:
1. Open the `.uproject` file in Unreal Engine 5
2. Build and play the game from the editor
